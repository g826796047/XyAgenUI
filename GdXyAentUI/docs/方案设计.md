# GdXyAentUI 高德 AGenUI 迁移方案

## 1. 目标和范围

GdXyAentUI 是与根目录 XyAgenUI 并行维护的独立版本。它把原项目的中文对话 Skill、全量 A2UI 回复、丰富组件组织、选择/表单交互、端侧 query 组装和浏览器参考预览迁移到高德 AGenUI catalog。原目录中的鸿蒙 Extended profile 不参与新项目运行。

迁移目标：

- 使用 A2UI `v0.9` JSONL 和高德独立 catalog `urn:a2ui:catalog:agenui_catalog`。
- 保留“所有回答都是 A2UI”的规则，简单回答由 `Column -> Text` 承载。
- 采用 AGenUI 真实字段和组件名，避免旧 `Text.content`、`Image.src`、`TextInput`、`CheckboxGroup` 等字段。
- 保留流式组件更新、数据模型绑定、丰富布局、表单选择和 FunctionCall query 模板。
- 将 AGenUI 端侧函数注册、深层 action 解析和未提供的计算能力列为宿主适配工作，不把它们伪装成协议内置能力。

## 2. 协议和目录依据

本项目协议快照位于 `references/protocol/` 和 `references/agenui/agenui_catalog.json`。快照来自高德开源仓库 `AGenUI/AGenUI` `main` 分支提交 `5c347a8352c1afff31879bcf5af4101df4f94137`。目录包含：

- 18 个 A2UI/基础协议组件：`Text`、`Image`、`Icon`、`Video`、`AudioPlayer`、`Row`、`Column`、`List`、`Card`、`Tabs`、`Modal`、`Divider`、`Button`、`TextField`、`CheckBox`、`ChoicePicker`、`Slider`、`DateTimeInput`。
- 4 个 AGenUI SDK 扩展：`RichText`、`Table`、`Web`、`Carousel`。
- 3 个 Playground/宿主注册组件：`Markdown`、`Chart`、`Lottie`。
- catalog 内置函数：校验、格式化、逻辑、token 和 `openUrl`。`sendMsgToXiaoyi`、三个鸿蒙链接函数属于宿主注册函数。

`catalogId`、组件字段和函数参数以本地 JSON catalog 为唯一依据；网页说明只作为来源索引。A2UI 核心协议不定义四则运算、query 模板插值、模型消息发送或自定义函数注册。

## 3. Skill 方案设计

### 3.1 回答路由

Skill 先识别目标、事实、未知项、替代方案、风险、决策点和下一步，再选择结构。它不设置组件数量指标，但要求组件表达真实内容关系：

| 内容 | 推荐结构 |
| --- | --- |
| 一句话事实 | `Column` + `Text` |
| 多主题摘要 | `Card` + `Column` + 标题/正文/`Divider` |
| 比较 | `Row`、`Table`、`Tabs` 或窄屏 `Column` |
| 步骤/清单 | `Column`、`List`、`CheckBox` 或 `ChoicePicker` |
| 图片/媒体 | `Image`、`Video`、`AudioPlayer` 加说明 |
| Markdown 文章 | 已注册时用 `Markdown`，否则用 `Text`/`RichText` 和结构化节点 |
| 需要用户决策 | `ChoicePicker`、`CheckBox`、`Slider`、`TextField`、`DateTimeInput` |
| 继续、确认、打开资源 | `Button` + FunctionCall |

不编造 URL、价格、库存、图片、状态或用户选择；没有实际决策点时不强行添加交互。

### 3.2 输出合同

每个回答必须是 JSONL：先 `createSurface`，再按流发送 `updateComponents` 和 `updateDataModel`。消息之外不输出裸文本。单个 `updateComponents.components` 可以包含一个或多个组件。所有组件 ID、子引用、路径、样式和动态值必须符合 catalog。

### 3.3 组件能力与用户交互

| 组件 | Skill 支持 | 作用 | 用户交互 |
| --- | --- | --- | --- |
| `Text` | 是 | 标题、正文、说明、动态结果 | 无 |
| `Image` | 是 | 真实图片 | 点击/资源行为由宿主扩展决定 |
| `Icon` | 是 | 内置或 SVG 图标 | 无 |
| `Video` | 是 | 视频 | 原生播放控制 |
| `AudioPlayer` | 是 | 音频 | 原生播放控制 |
| `Row` / `Column` | 是 | 横向/纵向布局 | 子组件决定 |
| `List` | 是 | 清单或数据列表 | 子组件决定；模板循环需端侧验收 |
| `Card` | 是 | 卡片容器 | 子组件决定 |
| `Tabs` | 是 | 视图切换 | 点击标签 |
| `Modal` | 是 | 浮层 | trigger/content 由端侧控制 |
| `Divider` | 是 | 分隔 | 无 |
| `Button` | 是 | 确认、继续、打开 | 点击 FunctionCall |
| `TextField` | 是 | 文本/数字输入 | 回写 `value` |
| `CheckBox` | 是 | 布尔勾选 | 回写布尔 `value` |
| `ChoicePicker` | 是 | 单选/多选 | 回写字符串数组 `value` |
| `Slider` | 是 | 范围数值 | 拖动回写数值 |
| `DateTimeInput` | 是 | 日期/时间 | 选择并回写值 |
| `RichText` | 是 | 受限 HTML 富文本 | 无；链接由宿主处理 |
| `Lottie` | 能力声明后 | 动画 | 播放/循环 |
| `Table` | 是 | 表格 | 无 |
| `Web` | 能力/域名声明后 | 网页 | WebView 内交互由宿主控制 |
| `Markdown` | 能力声明后 | Markdown 和流式追加 | 无 |
| `Chart` | 能力声明后 | 折线/柱/环图 | 无或宿主扩展 |
| `Carousel` | 是 | 图片轮播 | 翻页/拖动；加载图片受资源域名策略控制 |

“Skill 支持”表示模型可以按 catalog 生成并由新 validator 检查；不等于当前真机已经完成组件接入。`Markdown`、`Chart`、`Lottie` 的生成必须受宿主能力上下文限制。

`a2ui.allowedComponents` 若出现，表示该轮完整组件白名单；未提供时可使用 22 个协议/SDK 组件，3 个 Playground 组件仍须显式声明。任何函数调用（包含嵌套函数）都必须显式包含在 `a2ui.allowedFunctions`。这两项是本项目的宿主上下文合同，不是对官方 wire schema 的改写。

类型约定遵守官方 catalog：ChoicePicker 单选/多选均为字符串数组；TextField 含数字键盘均保存字符串；Slider 为数字；CheckBox 为布尔。query 参数只接收字符串/字符串数组，数字和布尔状态须先格式化。每个子组件只有一个父节点，按钮标签不重复挂到布局中。

### 3.4 FunctionCall 和灵活 query

组件状态由 AGenUI renderer 按 surface 保存。用户修改 `TextField`、`ChoicePicker`、`CheckBox`、`Slider` 或 `DateTimeInput` 时只改绑定路径，不请求模型。确认按钮读取当前路径并调用：

```json
{
  "id": "confirm",
  "component": "Button",
  "child": "confirm-label",
  "action": {
    "functionCall": {
      "call": "sendMsgToXiaoyi",
      "args": {
        "foods": {"path": "/meal/foods"},
        "people": {"path": "/meal/people"},
        "query": "我想吃${foods}，需要${people}人一起合作"
      }
    }
  }
}
```

端侧在点击时解析参数，按照选项展示顺序将数组转换成中文列表，替换 `${name}` 后再发送同一对话的新 user query。函数必须出现在 `a2ui.allowedFunctions` 且已通过 AGenUI `registerFunction` 注册。没有 `sendMsgToXiaoyi` 时可以静态展示输入，但不能生成不可执行的确认动作。

### 3.5 表单联动边界

输入之间不直接引用组件 ID，而是共享 data model 路径。AGenUI catalog 提供校验/格式化/逻辑函数，没有通用乘法和加法函数。人数自动计算总量需要宿主注册一个受限的 `calculateNumber`（并把它加入运行时 catalog/白名单），或在输入回写后由宿主计算并下发 `updateDataModel`。Skill 不生成任意表达式、`eval` 或假计算结果。

## 4. 端侧和 renderer 方案设计

### 4.1 AGenUI 端侧需要完成

1. 使用 AGenUI `SurfaceManager`/`Surface` 与 `AGenUIContainer` 接收 A2UI v0.9 JSONL，处理分片、结束、取消、错误和 surface 隔离。
2. 加载 `agenui_catalog` 对应的组件目录；注册 `sendMsgToXiaoyi`、`openSuperlink`、`openApplink`、`openDeeplink`，按需要注册 `calculateNumber`、`Markdown`、`Chart`、`Lottie` 等扩展。
3. 按 AGenUI API 对 `Button.action` 开启深层动态值解析（`registerDeepParseProperty("Button", "action")` 或当前 SDK 等价 API），否则 query 参数中的 `{path}`/嵌套函数可能不会在点击时解析。
4. 保存每个 surface 的真实输入/选择状态，回写 `TextField.value`、`CheckBox.value`、`ChoicePicker.value`、`Slider.value` 和 `DateTimeInput.value`，并让绑定文本、校验和依赖函数刷新。
5. 约束函数执行：校验 `allowedFunctions`、参数 schema、调用上下文、外链域名和重入状态；失败保留输入并允许重试。
6. `sendMsgToXiaoyi` 在发送前严格校验占位符与参数键、空值、数组元素类型和 query 长度；生成最终 query 后交给对话层发送。

### 4.2 浏览器参考 renderer 需要完成

新目录的 `renderer/` 只做离线参考：粘贴 JSONL、逐条解析、渲染常用 AGenUI 组件、模拟数据绑定和 FunctionCall，不实际调用模型或打开外链。它必须：

- 支持多组件 `updateComponents`、局部 `updateDataModel` 和 `deleteSurface`。
- 正确映射 `Text.text`、`Image.url`、`Button.child`、`TextField`、`CheckBox`、`ChoicePicker`、`Slider`、`DateTimeInput`、`Markdown`、`Table`、`Chart` 等字段。
- 在浏览器本地保存控件状态，点击确认时按当前值组装 query，并通过 `window.gdXyAgenUiHost.onFunctionCall(detail)` 回调。
- 对函数只实现安全模拟器：`sendMsgToXiaoyi` 只展示 query，链接函数只回调参数，禁止导航和任意 JavaScript。
- `Lottie` 和 `Web` 使用占位提示；`RichText` 按纯文本预览；`Carousel` 仅预览图片项；视频/音频/图片仅在资源域名允许时加载；图表是轻量预览，不等同于 AGenUI SDK 的原生渲染。
- 不把浏览器预览作为 HarmonyOS 设备兼容性证明。

### 4.3 尚未在本仓库证明的能力

高德 AGenUI catalog/schema 中存在但本地参考 renderer 或宿主仍需单独验收的能力包括：完整模板 children 实例化、所有组件样式、真实视频/音频/Web/导航、RichText HTML 细节、Markdown 流式追加、Chart/Lottie、无障碍、主题 token、动态窗口断点、FunctionCall 异步结果和设备生命周期。validator 通过只证明消息形状和本项目合同，没有替代真机验收。

当前网页预览的具体范围：

| 范围 | 网页参考实现 | 端侧仍需工作 |
| --- | --- | --- |
| Text、Image、Icon、Divider、Row、Column、Card | 基础样式、文本、允许域名图片及常用图标字符 | SDK 布局、图标/SVG、完整样式和资源加载验收 |
| List | 静态 children 和列表模板只读展示 | 模板内相对绑定输入回写、复用实例状态验收 |
| Tabs、Modal | 页签切换、浮层打开/关闭 | 原生窗口、无障碍、生命周期验收 |
| TextField、CheckBox、ChoicePicker、Slider、DateTimeInput | 绝对路径回写、单/多选、输入与本地动态刷新 | 输入法、平台日期格式、完整校验及状态隔离验收 |
| Button | checks、动态参数解析、白名单 FunctionCall、发送预览、防重复及回调失败重试 | 注册原生函数、接入真实 query 发送和业务权限 |
| Table、Carousel | 表格与可横向滚动的图片项 | 原生轮播分页、自动播放、拖动参数与布局细节 |
| Video、AudioPlayer | 浏览器媒体控件；无内置演示音视频源 | 真实资源、解码、权限与播放器体验 |
| RichText | HTML 源以纯文本降级展示 | 原生 HTML 标签、链接、安全策略 |
| Markdown、Chart | Markdown 基础格式和第一数据系列的轻量图表 | 完整 Markdown、多系列/负值图表、SDK 自定义组件注册 |
| Web、Lottie | 占位提示 | WebView 与动画引擎注册、资源和权限策略 |

本工作台每次预览一个 surface；新一轮调用 start/reset 会清理前一轮状态。真实对话中同时保留多条回答由宿主为每条回答管理独立 surface，不能把单工作台当作多 surface 容器。原生接口参见 `references/agenui/sdk-integration.md`。

## 5. 测试与验收

- `tools/validate_agenui.mjs` 校验 v0.9 envelope、catalogId、组件字段、root/子引用/循环/孤儿节点、数据路径、FunctionCall、query 占位符和能力白名单。
- 样例覆盖短文本、长文本、比较、图片、Markdown、选择、表单、链接和组件画廊。
- Node 测试覆盖 JSONL 分片、数据绑定、ChoicePicker 单/多选、TextField 输入、query 组装、空值拒绝和未知字段拒绝。
- 端侧使用 AGenUI HarmonyOS `SurfaceManager`/`Surface` 与 `AGenUIContainer` 加载同一 fixtures，验证输入回写、函数注册、深层 action 解析、query 发送和多 surface 隔离。

## 6. 迁移映射

| 原 XyAgenUI | GdXyAentUI |
| --- | --- |
| `ohos.a2ui.extended.catalog` | `urn:a2ui:catalog:agenui_catalog` |
| `Text.content` | `Text.text` |
| `Image.src` | `Image.url` |
| `TextInput` | `TextField` |
| `Checkbox`/`CheckboxGroup` | `CheckBox` 或 `ChoicePicker` |
| `Button.label` | `Button.child` 引用 `Text` |
| `TabContent` | `Tabs.tabs[].child` 引用普通组件 |
| `Extended.*` 样式字段 | AGenUI `styles` CSS 风格字段 |
| `getCheckboxGroupValues` | `ChoicePicker.value` 绑定数组；宿主自定义兼容函数可选 |
| `{{ a * b }}` | 宿主注册受限计算函数或发 `updateDataModel` |
