# A2UI 参考资料

本目录按用途分层，模型和工具默认只读官方快照与当前对话合同：

- `official/`：来自 A2UIRender 固定提交的 A2UI v0.9 envelope、公共类型、基础 catalog、Extended catalog 和消费端规则。协议字段以此处为准。
- `profile.md`：XyAgenUI 的消息顺序、组件图和丰富回答策略。
- `interaction.md`：Radio、Checkbox、Select、Toggle、Button 以及 FunctionCall 白名单合同。
- `forms.md`：使用官方 TextInput、Toggle、选择组件、数据模型路径和安全表达式实现表单联动。
- `renderer-contract.md`：浏览器参考 renderer 的边界。

根目录 [SKILL.md](../../SKILL.md) 链接了需要按场景阅读的文件。官方快照来源、分支和提交记录见 [official/README.md](official/README.md)。
